# Release Notes PR15

## CalTrack Coach MVP

- Added a HomeScreen card that suggests up to three foods based on the user's remaining daily calorie budget.
- Uses the existing USDA/fallback catalog and meal diary data; no new backend endpoint or camera flow is required.
- Provides meal-time labels, suggested quantity, calorie estimate, and a link to the existing food search screen.
- Treats suggestions as general nutrition guidance, not medical advice.
